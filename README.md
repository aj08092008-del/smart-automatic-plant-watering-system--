# Smart Automatic Plant Watering System

This project uses an Arduino UNO, a soil moisture sensor, a water pump, jumper wires, and a battery.

It uses a soil moisture sensor to check the moisture of the soil.

When the soil is dry, the water pump turns on automatically.

When the soil is wet, the water pump turns off automatically.

Components Used: Arduino UNO, soil moisture sensor, water pump, jumper wires, battery.
